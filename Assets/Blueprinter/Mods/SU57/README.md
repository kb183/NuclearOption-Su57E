# Local Su-57 assets

This directory is intentionally empty of aircraft resources in the public source repository.

The builder expects the private Su-57 model, textures, source data and Unity metadata here.
Restore them from an existing authoring project with Tools/import_local_assets.ps1, as described in [资源恢复说明](../../../../docs/ASSETS_ZH.md).

Files restored here remain ignored by Git. The repository's MIT license does not license third-party models, textures or game assets.
