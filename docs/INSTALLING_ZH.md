# 玩家安装与升级

安装文件只有 `Su-57.dll`，已包含 Su-57 飞机资源、动画与运行时修正。安装路径中的通用 Blueprinter 加载器仍是必需依赖。

## 安装

1. 准备 Nuclear Option、BepInEx 和已有的通用 Blueprinter。本工程已有开发基线为游戏 0.34.6、Blueprinter 2.1.1；未确认其他版本兼容性。
2. 完全退出游戏。
3. 从本仓库 Releases 下载 `Su-57.dll`，放到游戏目录的 `BepInEx/plugins/Su-57/Su-57.dll`。
4. 启动游戏，自行确认加载、选机、机库生成与实际飞行情况。

若仓库还没有 Releases，说明维护者尚未上传安装文件；GitHub 自动生成的 Source code ZIP 不能作为游戏插件安装。

## 从旧版升级

先把旧的 Su-57 安装文件备份到 plugins 目录外，再替换新 DLL。plugins 及其子目录中只应有一份 Su-57 插件。

需移出的历史 Su-57 文件包括：

- 独立 `Su-57_*.nobp` 或早期 Su-57 资源包。
- `SU57.GearMotion.dll`。
- 重复的 `Su-57.dll`。

保留通用 Blueprinter 和其他飞机 MOD；不要根据扩展名批量删除其他插件。

## 当前版本的验收状态

当前版本为 0.2.34，已有 DLL 内嵌 0.2.32 飞机资源。日志应显示 `Loading [Su-57 0.2.34]`。旧飞机资源中的断面由运行时补丁拆出并控制显示。

完整机体接缝、不同距离 LOD、部件脱落、修复及机库出生碰撞仍待使用者验收。历史 0.2.2 的无武器自动飞行记录不能替代当前版本验收。

## 问题反馈与卸载

出现问题时记录实际版本、复现步骤和相关日志片段，使用 Issues 中的 Bug report。分享日志前删除个人信息。

卸载时退出游戏，移出 Su-57.dll 即可；其他插件的依赖关系由各自 MOD 决定。
