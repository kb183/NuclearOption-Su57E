# Su-57 0.2.34 — 预发布

修正完整机体前后接口处持续可见的断面封边：断面独立显示，完好连接时隐藏，相邻分件脱落并实际分离后显示。

包括 0.2.33 的机库出生偏移修正和 0.2.32 的质量参考读取修正。

## 安装

需要 Nuclear Option、BepInEx 和通用 Blueprinter。当前开发基线为游戏 0.34.6、Blueprinter 2.1.1，其他版本兼容性未确认。

退出游戏，将附件 `Su-57.dll` 放入 `BepInEx/plugins/Su-57/`。升级时将旧 Su-57 的独立 nobp、`SU57.GearMotion.dll` 和重复 Su-57 DLL 移到 plugins 外；保留通用 Blueprinter。
